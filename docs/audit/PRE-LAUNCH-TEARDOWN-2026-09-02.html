Launch-blocking condition

The SHA-256 hash-chained audit log — the artifact the $499 report is sold on and the only reason a C3PAO accepts the evidence — does not exist in the product a CUI-handling customer runs.

The chain lives in compliance-firewall-agent/lib/audit/seed-anchor.ts and migrations 029/030, which run on the Vercel and Supabase plane the project's own documentation states is not CUI-safe. The Mode B container writes proxy_events with no hash column, no previous-hash column and no signature. Selling a tamper-evident deliverable that the shipped container cannot produce is the one failure a defense buyer never forgives.

Methodology and its one hard limit

Every finding below was read from the repository working tree at commit b88b7ee, executed locally, or fetched live over HTTPS. Directory sizes, pattern counts, link resolution and the TypeScript compile were measured, not estimated.

Live HTTP probing of houndshield.com was refused by this environment's egress policy — the proxy returned 403 to CONNECT www.houndshield.com:443 on every attempt. No assertion in this document claims a live response code. Runtime behaviour of the deployed site is anchored to docs/gtm/LIVE-PRODUCTION-AUDIT-2026-08-15.md, which states it was read from production, and every such assertion is tagged accordingly in Section 5.

The 180-Day Operations Calendar

Six immutable 30-day phases. One unambiguous, testable operational task per day unit, Day 1 through Day 180, with no repeats and no placeholders. Sequence is load-bearing: Phase 2 cannot start until Phase 1 has produced a deployable production path, and the partner approach in Phase 5 is unsellable until the hash chain from Phase 2 exists.

Phase 1

Production Path Stabilization & High-Conversion Landing Flow Isolation

Exit condition: a production deploy completes, a test purchase produces a report_orders row plus a receipt plus an alert, and the homepage routes to the $499 order path.
