# Contact Ledger

The only record of who has actually been contacted. Written by the daily loop,
read by you.

One row per human being. A row without a specific researched fact is not a row
and gets discarded rather than softened, because generic messages are why the
previous outreach material produced nothing.

Status values, and only these four: DRAFTED, SENT, REPLIED, CLOSED. There is no
value for "planned" and none for "researched," by design. Law three.

## How the loop writes here

When the Gmail connector is available in the session, the loop creates the
message as a Gmail draft and records the row here with status DRAFTED.

When it is not available, which is the case for the scheduled weekday Routine,
the loop appends the full finished message text to the Outbox section at the
foot of this file instead. Same status, same obligation. You copy it out and
send it. The message still exists and is still addressed to a named person,
which is what Law one requires; only the delivery mechanism changed.
